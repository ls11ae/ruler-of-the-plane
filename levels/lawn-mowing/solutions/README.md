# Solutions of the booth lawns

Put the chair's solver solutions here, one file per instance in the pyutils27 solution format:
`<instance_uid>.solution.json` (e.g. `lawn3_2s3.solution.json`). Then run `npm run levels`: the game
shows the longest tour as the target ("Ziel vom Löser"), starts the cutters on the tours' first points
and animates the tours in the theory view. A test checks that every solution mows its whole lawn.
