# Legacy data from the Unity version

Copied from [github.com/kbuchin/ruler](https://github.com/kbuchin/ruler) at commit `b2d1a2d`
(`unity/Assets/*/Levels/` and `ingameText.md`), without the Unity `.meta` files.

Read-only: `scripts/import-ipe.ts` converts the levels to `public/levels/*.json`. Fix problems in the
importer, not here. Format, level order and pitfalls: `docs/legacy-unity-notes.md`.
