# Style mockup

The visual target for the booth edition: five screens of the style mockup made on 16 October 2026, each
1280 × 800.

| File | Screen | Art |
| --- | --- | --- |
| `start-map.webp` | Start screen: map of the kingdom, one place per game | Cartography Pack |
| `licht-ins-verlies.webp` | Art gallery on Unity level 4 with five of eight torches | Scribble Dungeons |
| `erobere-das-land.webp` | Voronoi game with land, water, cities and a ghost castle | Cartography Pack |
| `gassi-gehen.webp` | Fréchet game with the theory panel (free-space diagram) | Cartography Pack, Animal Pack |
| `rasenmaehen.webp` | Lawn mowing with two 3 × 3 cutters | Scribble Dungeons |

The geometry in the screenshots is computed (visibility polygons, Voronoi cells, free-space diagram,
coverage of the cutters); the numbers are sample values, and "[Wert]" marks the solver target that is
still missing. Match the look (ink on paper or parchment, colour only for players, light and
territories, Eagle Lake for titles, Patrick Hand for text), not the exact layout.
